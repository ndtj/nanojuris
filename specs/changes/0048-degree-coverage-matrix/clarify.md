# Clarificações

- “Cobertura nacional” nesta mudança significa cobertura institucional
  mapeada, com lacunas explicitamente contadas; não significa que todos os
  documentos históricos ou todas as unidades judiciais já possam ser baixados.
- `CJPG`/`CJSG` são usados como nomes de coleção apenas quando a fonte os
  declara ou o contrato local os comprova.
- Uma linha `implemented` representa contrato runtime local, não garantia de
  disponibilidade permanente live. A evidência live é mantida separadamente.
- A primeira versão não promove automaticamente candidatos Juscraper; cada
  provider continua sujeito ao fluxo SDD próprio.
