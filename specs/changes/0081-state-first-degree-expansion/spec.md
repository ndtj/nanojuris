# 0081 — primeiro grau estadual

Status: `proposed`

Fechar 27 superfícies estaduais de sentenças/decisões de primeiro grau,
distinguindo jurisprudência textual de consulta processual, DataJud, diários e
catálogos.

- **AC-001:** cada TJ tem contrato explícito de primeiro grau ou bloqueio terminal.
- **AC-002:** grau, classe e autoridade são validados em cada registro aceito.
- **AC-003:** filtros, segunda página, vazio e inteiro teor possuem evidência.
- **AC-004:** nenhum bloqueio é contado como cobertura.
