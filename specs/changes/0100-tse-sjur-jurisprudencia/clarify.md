# Clarify — TSE SJUR

- O TSE é fonte eleitoral superior; não deve ser apresentado como cobertura
  automática dos 27 TREs.
- `temInteiroTeorPDF=true` é somente indicação de disponibilidade. A rota PDF
  pública foi validada para identificadores observados; IDs não observados
  continuam rejeitados pelo adapter.
- Um HTTP 200 com paginação ignorada não prova janela paginada nem cobertura
  completa de consultas grandes.
