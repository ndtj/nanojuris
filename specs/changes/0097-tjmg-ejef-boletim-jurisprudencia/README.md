# SDD 0097 — TJMG/EJEF Boletim de Jurisprudência

Implementação de uma superfície pública, curada e reproduzível do Boletim de
Jurisprudência da EJEF/TJMG, usando a coleção DSpace oficial e preservando a
distinção entre coleção parcial e acervo integral.

Status: `in_progress` até a execução dos gates locais e decisão operacional.
