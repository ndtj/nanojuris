# Spec da própria especificação

- O pacote possui problema, escopo, requisitos, critérios, design, tarefas,
  verificação, rastreabilidade e threat model.
- Cada critério `AC-NNN` é verificável por relatório ou comando local.
- Cada tarefa `Tn` aponta para uma entrega auditável.
- O pacote não altera o catálogo gerado nem implementa provider.
