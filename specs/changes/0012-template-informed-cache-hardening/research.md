# Pesquisa

O template analisado é um snapshot do Scrapling (Karim Shoair/D4Vinci), cujo
upstream declara BSD-3-Clause. O snapshot recebido não traz o arquivo de
licença, por isso não houve cópia literal. Foram aproveitados apenas padrões
genéricos de persistência e tolerância a cache inválida; componentes de stealth
e rotação de proxy não são compatíveis com uso responsável de fontes públicas.
