# Spec da própria especificação

- O pacote separa pesquisa, clarificações, requisitos, design, tarefas,
  verificação, rastreabilidade e threat model.
- Cada requisito possui critério `AC-NNN` e tarefa correspondente.
- A matriz usa o template local como fonte de capacidades, não como autorização
  para copiar módulos sem adaptação ao domínio jurídico.
