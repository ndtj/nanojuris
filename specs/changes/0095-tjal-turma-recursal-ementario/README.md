# SDD 0095 — TJAL Turmas Recursais

Pacote para adicionar a colecao oficial de ementas das Turmas Recursais do
TJAL. A colecao e recursal e nao conta como CJPG ou CJSG.

Status: `in_progress`

O provider usa somente PDFs publicados pelo TJAL, sem formulario de consulta,
sem autenticacao e sem tentativa de contornar desafios. Volumes que nao
permitem extracao textual permanecem explicitamente `document_unavailable`.
