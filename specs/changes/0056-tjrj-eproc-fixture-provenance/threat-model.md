# Threat model

- **Proveniencia:** identificador, processo e textos sao explicitamente
  ficticios.
- **Privacidade:** nenhum nome de parte, cookie, token ou credencial e incluido.
- **Integridade:** o teste verifica UF RJ, processo `.8.19`, dominio TJRJ e
  identidade do provider.
- **Acesso:** nenhum controle de acesso foi contornado.
