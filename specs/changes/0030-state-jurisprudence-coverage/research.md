# Pesquisa — cobertura estadual

Status: in_progress

## Linha de base

O catálogo atual documenta fontes para tribunais estaduais em diferentes tiers,
incluindo runtime, candidates e bloqueios. A cobertura de uma unidade federativa
não implica cobertura histórica, integral ou de todos os tipos de decisão.

## Candidatos iniciais

- TJES: API JSON pública tratada por 0025;
- TJRJ ejuris: candidate complementar ao eproc;
- TJRN: candidate sem adapter runtime;
- TJMG: bloqueado enquanto o acesso depender de OCR de CAPTCHA; parser de
  documento público pode ser avaliado isoladamente;
- TJRO: runtime atual é contexto de precedentes, não jurisprudência ampla;
- TJAP: bloqueio de automação observado externamente.

## Próxima evidência

Cada candidato requer pesquisa oficial atual, fixture e SDD próprio.
