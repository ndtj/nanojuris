# Decisoes esclarecidas

| Questao | Decisao |
| --- | --- |
| Um portal geral conta como CJSG? | Nao, ate provar contrato de segundo grau. |
| Um modulo Juscraper prova disponibilidade? | Nao; serve apenas como evidencia de pesquisa. |
| Bloqueio e zero resultados sao equivalentes? | Nunca. |
| Licenca interna adicional bloqueia teste tecnico local? | Nao, mas uso tecnico nao autoriza publicacao ou deploy. |
| O programa cria 27 adapters cegamente? | Nao; cria 27 workpacks e implementa somente rotas oficiais comprovadas. |
