# SDD 0096 — TJAL ESMAL Banco de Sentenças

Pacote de implementação do banco público de sentenças selecionadas da Escola
Superior da Magistratura de Alagoas (ESMAL/TJAL).

Escopo: coleção curada de decisões de primeiro grau, com busca por categoria e
palavra-chave, links oficiais para PDFs e paginação pública por página. Não é
uma promessa de cobertura integral do CJPG do TJAL.

## Estado

Implementação técnica local concluída, com validação live bounded e federação
como fonte parcial. A limitação curada e a política de retenção continuam
explícitas; nenhuma cobertura integral é declarada.
