# Clarify

- **Q1**: podemos copiar a fixture TJSP para provar TJRJ/TJSC? **Não**; ela
  prova apenas o parser compartilhado e não os contratos específicos do host.
- **Q2**: podemos inferir novas rotas dos dossiês? **Não**; rotas sem fixture ou
  validação autorizada permanecem como lacunas.
- **Q3**: falta de ID pode virar fallback pelo processo? **Sim**, quando houver
  número de processo; sem ambos, o resultado é inválido.
