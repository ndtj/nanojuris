# `trt4_sumulas_jurisprudencia`

Provider opt-in para a página oficial de Súmulas e materiais relacionados do
TRT4. A página pública expõe textos de súmulas e links oficiais para atos,
acórdãos e documentos de apoio.

Esta é uma coleção curada e contextual: não é a busca geral Falcão nem o
acervo integral do TRT4. Cada registro aceito preserva `authority=TRT4`,
`branch=labor`, `degree=second`, `instance=second`, coleção, tipo documental,
URL, `raw` e `SourceTrace`. O documento oficial só é buscado depois que o
resultado foi observado na sessão.

HTML inválido, mudança de schema, 403, 429, timeout e erro de transporte são
classificados explicitamente e nunca convertidos em vazio. Não há CAPTCHA,
credenciais ou bypass. O inteiro teor depende do documento oficial vinculado e
não é declarado no resultado de busca.

Evidência live: `docs/provider-discovery/trt4-sumulas-live-20260910.json`.
