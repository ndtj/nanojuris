# Maintainers

## Lead Maintainer

**Luciano Molero** (`@lucmolero`) is the principal maintainer of NanoJuris.
He is responsible for the technical direction, architecture, provider
contracts, releases, security decisions and project continuity.

## Institutional Context

NanoJuris is hosted in the `ndtj` GitHub organization as part of the academic
context of the [Nucleo de Direito, Tecnologia e Jurimetria (NDTJ)](https://ndtj.com.br/).
The organization provides institutional context and a collaborative home for
the project. It does not replace the named technical maintainer or erase
individual authorship.

## Contributors

Contributors are recognized through commit history, pull requests, release
notes and `CITATION.cff`. New maintainers are added through the governance
process documented in [GOVERNANCE.md](GOVERNANCE.md).

## Ownership And Credits

The repository may be owned by the NDTJ organization while Luciano Molero
remains the principal technical maintainer and original author of the project.
GitHub preserves commit authorship and contribution credit during a repository
transfer.
