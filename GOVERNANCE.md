# Governance

## Project Identity

NanoJuris is an open source project created and principally maintained by
Luciano Molero. It is hosted by the NDTJ GitHub organization and developed in
the academic context of the Nucleo de Direito, Tecnologia e Jurimetria.

## Decision Roles

- **Lead Maintainer:** Luciano Molero. Final responsibility for architecture,
  releases, security, public contracts and technical consistency.
- **Institutional context:** NDTJ. Academic and collaborative context for the
  project; it does not imply that NDTJ endorses every implementation detail or
  that the project is an official product of a court or public body.
- **Contributors:** people who submit code, documentation, research,
  fixtures, tests or provider contract evidence.

## Contributions

Contributions should arrive through issues and pull requests. Changes to
providers must include reproducible evidence, fixtures without credentials,
tests and documentation of source limits. The project does not accept captcha,
login, WAF or access-control bypasses.

## Maintainer Changes

A new maintainer may be nominated by the Lead Maintainer based on sustained,
reviewed contributions and demonstrated understanding of the project contract.
Changes to repository ownership do not by themselves change the technical
maintainer role.

## Attribution

Contributors retain credit for their commits and pull requests. Releases and
the citation file identify the software authors and the current project
context. See [MAINTAINERS.md](MAINTAINERS.md) and [CITATION.cff](CITATION.cff).
